Experience

Full-Stack Engineer

Rogo Solutions JSC

Jan 2024 to present

A 20-person IoT startup. I am the only engineer on the cloud side, so the dashboard, the API, the message pipeline and the deploy path are all mine. The platform serves 640k users and 69k devices for 26 partner projects, at roughly 2.6M API requests a day and 15.5k concurrent MQTT connections.

  • Build the partner dashboard in Next.js and TypeScript, with React Query for server state, Ant Design and Tailwind for the interface, and internationalisation. One deployment serves 26 partner projects, configurable per project.
  • Attribute-based authorisation in which the permission set is encoded into a compact custom claim on the JWT, so a request is authorised from the token itself instead of a database lookup on every call. The React app derives the same rules through CASL, so the interface and the API agree on what is allowed.
  • Device state streaming on Kafka with MQTT ingestion: a consumer that coalesces repeated updates into batched writes and commits offsets after the write, autoscaled by KEDA on consumer group lag.
  • Run the platform on Kubernetes and AWS ECS, with Prometheus, Loki and Grafana for metrics and logs across three clusters, and the staging to production path on GitHub Actions, GitLab CI and ArgoCD.
