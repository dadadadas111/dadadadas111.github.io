# Mobile App Next Phase Plan

## Phase 1.1 — MVP hardening

Goal: make the first shipped app safe to use daily.

Focus:

- edit flows for schedule, progress, finance, and journal
- safer import flow with preview and rollback
- better validation on time/date and numeric inputs
- stronger journal templates by day type
- polish state refresh and empty states

## Phase 1.2 — Reminder quality

Goal: make journaling and check-ins feel proactive, not manual.

Focus:

- better notification copy
- separate reminder windows per journal mode
- optional check-in reminders for progress and finance
- in-app reminder dashboard

## Phase 1.3 — Dashboard depth

Goal: make the app useful for weekly and monthly reflection.

Focus:

- charts instead of only cards/progress bars
- better category breakdown
- schedule/progress/finance/journal correlations
- weekly and monthly review screens

## Phase 2 — Drive integration

Goal: make reinstall and device migration smoother.

Focus:

- Google sign-in
- upload backup bundle to user-owned Drive location
- list backups
- restore from selected backup
- version checks and restore safeguards

## Phase 3 — Structured recurrence and templates

Goal: reduce data entry friction.

Focus:

- recurring schedule blocks
- recurring finance templates
- recurring journal prompt templates
- objective templates by pillar

## Phase 4 — Optional backend

Only start this phase if you truly need:

- multi-device live sync
- sharing
- automation outside the phone

Focus:

- event log sync protocol
- conflict handling strategy
- auth model
- server-generated summary/dashboard APIs
