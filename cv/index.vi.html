Kinh nghiệm

Kỹ sư Full-Stack tại Rogo Solutions JSC

01/2024 đến nay · Hà Nội

Phụ trách toàn bộ phần cloud của một nền tảng IoT đa đối tác: dashboard cho đối tác, API, luồng message và triển khai. Hệ thống chạy vài triệu request API mỗi ngày, với khoảng 15.000 kết nối MQTT đồng thời và xấp xỉ 12 triệu message thiết bị mỗi ngày.

  • Xây dựng dashboard đối tác bằng Next.js và TypeScript, dùng React Query quản lý server state, Ant Design và Tailwind cho giao diện, kèm đa ngôn ngữ. Một lần triển khai phục vụ nhiều dự án đối tác, cấu hình riêng theo từng dự án.
  • Phân quyền theo thuộc tính (attribute-based): bộ quyền được mã hóa vào một custom claim gọn trong JWT, nên mỗi request được xác thực ngay từ token thay vì phải truy vấn cơ sở dữ liệu mỗi lần gọi. Ứng dụng React dùng cùng bộ luật đó qua CASL, để giao diện và API thống nhất về những gì được phép.
  • Streaming trạng thái thiết bị trên Kafka với ingestion từ MQTT: một consumer gộp các cập nhật lặp lại thành batch ghi và commit offset sau khi ghi xong, tự động scale bằng KEDA theo độ trễ của consumer group.
  • Vận hành nền tảng trên Kubernetes và AWS ECS, với Prometheus, Loki và Grafana cho metric và log, và luồng staging đến production qua GitHub Actions, GitLab CI và ArgoCD.
