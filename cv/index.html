Experience

Backend / Platform Engineer — Rogo Solutions JSC

Jan 2024 – Present · Hanoi

A ~20-person IoT startup, where I am the only engineer on the cloud side — the API, the message pipeline, the clusters and the deploy path. It serves 640k users and 69k devices for 26 partner projects, at roughly 2.6M API requests/day and 15.5k concurrent MQTT connections, across 3 Kubernetes clusters and AWS ECS.

  • Device data plane. Designed and operate the state pipeline — EMQX MQTT into a 3-broker Strimzi Kafka cluster (RF3), then a decoding agent and a coalescing consumer that KEDA autoscales on partition lag, writing to MongoDB. Moved partner traffic onto it from a single-node broker via an external listener.
  • Multi-tenancy. Built the partner-facing surface for 26 projects: an attribute-based authorization layer (v1 → v2), per-project SMS providers, and phone + OTP sign-in.
  • Operations. Took the platform from no monitoring at all to Prometheus, Loki and Grafana across 3 clusters plus CloudWatch, so failures are diagnosed from a dashboard rather than by guessing. Run the staging → production path across 4 repositories (GitHub Actions, GitLab CI, ArgoCD), deploying to ECS, Kubernetes and the MQTT workers.
  • Performance work. The expensive problems were found by profiling, not guessing: an unindexed $lookup that took 11 minutes and was about to force a database tier upgrade; RS256 token verification running per request inside auth middleware, which no APM was showing; a partner SDK stampeding every hour on the hour. Each was a small change once it was found.
  • Codebase health. Brought back a test suite that had become unrunnable — it exhausted memory and froze dev machines — by moving Jest 24 → 29 to transpile-only tests with a separate type-check, then gated CI on it. Also removed 1,667 lines of dead code with no behaviour change.
  • Self-hosted edition. Designed an on-prem deployment profile (Firebase, DynamoDB and S3 replaced by Keycloak, MongoDB and MinIO) with an auth migration that preserves existing logins, and validated it with a boot PoC that surfaced 10 concrete blockers before the company committed to it.
