  • Attribute-based authorisation in which the permission set is encoded into a compact custom claim on the JWT, so a request is authorised from the token itself instead of a database lookup on every call. Selected Projects

IoT Cloud MCP (TypeScript, NestJS, MCP, Redis) · github.com/dadadadas111/iot-cloud-mcp
An MCP gateway that lets Claude, ChatGPT and n8n query and control a production IoT platform: fifteen tools over JSON-RPC, with the device REST API behind them. Multi-tenant, and sessions in Redis are scoped per project and per user — a tool call is authorised by the session, not trusted because the model asked for it.

Novel Studio (TypeScript, NestJS, Anthropic SDK, PostgreSQL with pgvector) · github.com/dadadadas111/novel-studio
Token cost normally grows with the story until it stops being affordable. Three tiers keep the prompt bounded at any length: a canon store of extracted facts, a rolling summary that is recursively recompressed, and top-k pgvector retrieval. The model never sees the raw novel.

MathSketch Tutor (TypeScript, NestJS, mathjs, MCP) · github.com/dadadadas111/mathsketch-tutor
Feedback on a handwritten maths problem. A computer-algebra engine, exposed to the model as an MCP tool, decides whether a step is right and the model only writes the explanation — so it cannot invent a correction that is wrong.
